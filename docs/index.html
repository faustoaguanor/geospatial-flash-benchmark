EL RETO DE DESARROLLO

Controles de calidad para
un catastro ficticio de Quito.

Crear un panel en español que cargue GeoJSON, muestre predios, detecte problemas de atributos y geometría, compruebe superposiciones y diferencias de superficie, y exporte incidencias. Todo se procesa localmente en el navegador.

Cada modelo generó su propio conjunto de datos con semilla fija cerca de seis sectores de Quito. Por ello, los totales de incidencias no son directamente comparables. Son predios de demostración, no información municipal oficial.

SIG / PROVISIONAL

DeepSeek lidera esta revisión.

Categorías explícitas de contacto e indicadores de superposición para ambos predios. Las tres omiten un hueco exterior y la equivalencia de duplicados con anillos invertidos.

ARQUITECTURA / PROVISIONAL

MiMo separa bien las responsabilidades.

Un motor independiente del DOM, módulos de interfaz específicos y carga diferida del mapa. El tratamiento de geometrías mal formadas requiere mejoras en una versión derivada.

DISEÑADO PARA REPRODUCIRSE

Preservar el experimento.
Mostrar sus límites.

Un benchmark comunitario independiente curado por faustoaguanor. Ningún proveedor de modelos lo patrocina ni lo respalda.

  1. Preservar las implementaciones originales.

    Hashes SHA-256 de referencia para 107 archivos. Las instalaciones, pruebas y compilaciones utilizan copias temporales.

  2. Comprobar más allá de las pruebas propias.

    16 casos diagnósticos compartidos por modelo, con adaptadores de esquema explícitos y resultados originales.

  3. Distinguir evidencia de afirmaciones.

    Se identifican por separado los resultados observados de pruebas y compilaciones, las métricas reportadas y el comportamiento no verificado en navegador.

  4. Publicar mediante un mismo flujo.

    Las pruebas originales deben aprobarse. Las compilaciones independientes de Vite conservan rutas relativas. Un único artefacto de Pages incluye la comparativa y las tres aplicaciones.

Estos predios son sintéticos y de demostración.

No se evaluaron datos catastrales oficiales, exactitud posicional frente a un levantamiento ni conformidad municipal. La tolerancia de superficie del 5 % es experimental. Cada modelo utilizó datos generados distintos; sus cantidades de incidencias no pueden clasificarse como si compartieran un conjunto de referencia.
