THE DEVELOPMENT BRIEF

Quality checks for
a fictional Quito cadastre.

Build a Spanish-language dashboard that loads GeoJSON, maps parcels, detects attribute and geometry issues, checks overlaps and area differences, and exports findings. All processing runs locally in the browser.

Each model generated its own seeded dataset near six Quito sectors. That makes incidence totals unsuitable for direct comparison. These are demonstration parcels, never official municipal information.

REPRODUCIBLE BY DESIGN

Preserve the experiment.
Make the limits visible.

An independent community benchmark curated by faustoaguanor. No model provider sponsors or endorses it.

  1. Freeze the original submissions.

    SHA-256 baselines for 107 files. Installs, tests and builds use temporary copies.

  2. Verify behavior beyond self-tests.

    16 shared diagnostic cases per model, with explicit schema adapters and raw outputs.

  3. Separate evidence from claims.

    Observed test/build results, reported development telemetry and unverified browser behavior are labeled separately.

  4. Publish through one pipeline.

    Original tests must pass. Independent Vite builds retain relative paths. One Pages artifact contains the landing page and three applications.

These are synthetic demonstration parcels.

No official cadastre, surveyed positional accuracy or municipal conformity was evaluated. The 5% surface tolerance is experimental. Each model used different generated data; incidence counts cannot be ranked as if they shared a reference dataset.
