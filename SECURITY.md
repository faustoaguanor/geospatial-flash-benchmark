# Security

This is an experimental, static benchmark with frozen historical applications. It is not a supported cadastral production system. Use synthetic data when reproducing issues.

Report vulnerabilities through GitHub's private vulnerability reporting feature if enabled. If unavailable, contact the repository owner through an existing private channel; do not post credentials or working exploit payloads containing personal data in public issues. Ordinary non-sensitive defects can be filed as issues.

Fixes to the site and deployment tooling can be accepted here. Application vulnerabilities are documented against the immutable submissions and can be addressed in a separately identified derivative. The audit is selective, not a penetration test; dependency vulnerability advisories were not independently checked in this restricted environment.
